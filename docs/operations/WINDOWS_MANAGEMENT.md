# Windows Server control plane
Run React/TypeScript UI as IIS site `ShadowAPI-Web`, Windows Go API as `ShadowAPI.Management.Api` and separate `ShadowAPI.Management.Sync`, `ShadowAPI.Management.Jobs` Windows Services with individual DisplayName, Description, service principal, Event Log channel, status probes and recovery config. Microsoft SQL Server on Windows (dedicated instance/host recommended), preferably HA when licensed. Reverse proxy only exposes required HTTPS endpoints. UI faults may not stop API services. SQL faults do not terminate edge policies/ingest.

Windows installer (.msi/.exe) features: UI, Management API, Sync, Jobs, SQL Server connectivity/config validation (SQL Server installation/ownership as separate controlled procedure), selected integration utilities. Explicit secrets management, cert rotation, firewall rules, backup/restore plan, service-by-service repair and uninstall. Sign installers. Windows versions, IIS/SQL versions, .NET/Go support where applicable must be pinned in release compatibility sheet, not guessed.
