# ClassiGuard Shadow API Hunter — JSON Schema Specifications

This package provides standard JSON Schema (Draft-07) schemas matching the platform's core data models.

## Specifications

- `api_observation.schema.json`: Validates wire observation payloads from collectors and gateway log forwarders.
- `api_asset.schema.json`: Validates discovered endpoint inventory records.
- `finding.schema.json`: Validates security findings, risk scoring assessments, and compliance attestations.
- `policy_snapshot.schema.json`: Validates autonomous edge policy snapshots and inspection rule sets.
